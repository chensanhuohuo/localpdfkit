Licensing and Attribution

LocalPDFKit is an independent PDF tools website operated under its own brand at localpdfkit.com. This page explains our branding boundary, upstream open-source notices, and how to access source-code and report an intellectual-property concern.

Independent Brand

LocalPDFKit is not the official website of BentoPDF or any other upstream project. Our name, logo, domain, screenshots, tutorial copy, and page design are part of the LocalPDFKit brand unless a page explicitly says otherwise.

You may not reuse LocalPDFKit brand assets in a way that confuses users about source, affiliation, or ownership.

Upstream Open Source

LocalPDFKit is built from and around upstream open-source software, including the BentoPDF project and other third-party PDF libraries. Their original licenses, notices, and attribution requirements continue to apply to the relevant code and optional components.

We do not claim ownership over upstream code we did not create. We claim ownership only over our own brand assets, original page copy, and project-specific modifications.

Source Code and Compliance

LocalPDFKit is being operated on an AGPL route. Source availability details for this deployment should be published on the dedicated Source Code page, together with the public repository and any release instructions used for compliance.

Public source repository: https://github.com/chensanhuohuo/localpdfkit.

Source code requests, compliance questions, and notice corrections can be sent to contact@localpdfkit.com.

This page is informational only and does not constitute legal advice. If you plan to redistribute, rebrand, self-host, or build commercial services on top of upstream components, review the relevant licenses yourself and obtain legal advice when needed.

Third-Party Components

  • Core site functionality may rely on open-source libraries such as PDF.js, pdf-lib, and other browser-side PDF tooling.
  • Some advanced or optional processing modules can carry copyleft or reciprocal license obligations. Review each component before enabling it in a redistribution or closed-source environment.
  • Vendor-specific license texts and notices included in this repository remain the authoritative reference for those components.

Original LocalPDFKit Content

  • LocalPDFKit logos, icons, social images, layout choices, and editorial copy are reserved unless we explicitly publish them under a separate license.
  • Tutorials, help content, and category pages should not be copied verbatim into another commercial or ad-supported website.
  • Tool functionality may be inspired by upstream open-source projects, but our page wording and branding are intended to stay distinct.

Attribution Boundary

LocalPDFKit should not be represented as the official site, support channel, or documentation portal for BentoPDF.

Where attribution is required, we acknowledge that this project is based on upstream open-source work, including BentoPDF, and we maintain a separate brand to reduce user confusion.

If you believe a page, asset, or notice on LocalPDFKit infringes your rights or fails to satisfy an attribution obligation, contact us at contact@localpdfkit.com with the affected URL and a clear description of the issue.

Start with the public GitHub repository or email us and include the page URL, the component or asset in question, and the reason for your request.
