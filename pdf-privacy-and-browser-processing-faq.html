PDF Privacy and Browser Processing FAQ

These answers explain what LocalPDFKit means by browser-based processing, where the limits are, and what users should still review before handling sensitive documents.

What does browser-based processing actually mean?

It means the main processing logic can run inside your browser session on your device instead of relying on a remote application server for routine document handling.

Does browser-based always mean zero network activity?

Not necessarily. Some features may load scripts, WebAssembly modules, OCR language files, or other configured assets when they are first needed.

What is stored in my browser?

Settings such as language choice and interface preferences may be stored locally. Future consent, analytics, or advertising features would also create their own browser storage when enabled.

Should I still review sensitive documents before sharing?

Yes. Browser processing can reduce routine uploads, but it does not replace your own review process for confidential, regulated, or business-critical files.
