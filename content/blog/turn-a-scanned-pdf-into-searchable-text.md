If a PDF looks readable but you cannot select or search any text, it is probably just a collection of scanned images. That is normal for paper documents, photocopies, and older archives. To make those files more useful, you need OCR.

OCR stands for optical character recognition. In plain language, it means software looks at the image of each page and tries to identify the letters inside it.

## How to tell whether a PDF needs OCR

Try these quick checks:

- search for a word you can clearly see on the page
- try selecting one line of text with your cursor
- paste copied text into a note

If none of that works, OCR is likely the right next step.

## Start with the cleanest scan you have

OCR quality depends heavily on source quality. Before you run [OCR PDF](/ocr-pdf), improve the source if possible.

The biggest factors are:

- skewed pages
- low contrast
- blurry camera photos
- handwriting mixed with printed text
- very small text

If the PDF is damaged or pages render strangely, repair it first. [Repair PDF](/repair-pdf) is the better first stop in that case.

## Run OCR with realistic expectations

OCR is helpful, but it is not magic. Even a good OCR result may still need review when the source includes:

- old photocopies
- folded or shadowed pages
- multi-language documents
- stamps over text
- dense financial tables

Think of OCR as a workflow accelerator, not an excuse to skip checking the result.

## What improves OCR results the most

### Better page contrast

Dark text on a lighter background is easier to recognize.

### Straight pages

Tilted scans reduce recognition accuracy. If pages are visibly crooked, correct that before OCR.

### Consistent language

OCR performs better when the document mostly matches the expected language.

### Reasonable file size after scanning

Over-compressed scans can blur letters together. If you control scanning settings, avoid crushing quality too early.

## What to do after OCR

Once the text layer exists, you can move into other workflows more easily:

- use [PDF to Text](/pdf-to-text) for extraction
- compress the PDF for easier sharing
- search the document before archiving it
- copy short passages into notes or case files

OCR is often not the final step. It is the bridge that unlocks better downstream workflows.

## Common OCR mistakes

### Assuming every page is accurate

Always spot-check names, totals, dates, and headings.

### Running OCR on a badly damaged file

If the PDF opens inconsistently or pages are corrupted, repair first.

### Using OCR when the PDF already has selectable text

Some PDFs only look like scans but already include a text layer. Check that first so you do not do extra work for no reason.

## When this matters most

This tutorial is especially useful for:

- scanned contracts
- paper records that need archive search
- receipts and invoices from phone scans
- school, legal, and administrative records
- image-only PDFs that need text extraction later
