Application portals rarely want everything you have. They want the relevant pages, in the correct category, under the upload limit. That is why page extraction is one of the most useful PDF cleanup tasks for real-world submissions.

## Typical situations

This is common when you need to upload:

- selected passport pages
- one section of a bank statement pack
- specific pages from an employment contract
- a named annex from a longer report

Sending only what is requested makes the submission clearer and often faster to review.

## Step 1: Identify the exact required pages

Before using [Extract Pages](/extract-pages), write down the page numbers or categories you need. This is especially important when the same long PDF contains several unrelated sections.

## Step 2: Extract only the necessary pages

Open [Extract Pages](/extract-pages) and keep only the relevant pages. If you later need to rebuild a grouped packet from several sources, you can combine the extracted results with [Merge PDF](/merge-pdf).

## Step 3: Name the output clearly

Use file names that match the portal slot, such as:

- `passport-id-pages.pdf`
- `employment-letter-pages.pdf`
- `bank-statement-mar-apr.pdf`

Reviewers should not have to guess what the file contains.

## Step 4: Remove extra pages instead if that feels simpler

If the document mostly stays the same and only a few pages need to disappear, [Delete Pages](/delete-pages) may be the faster route. Use whichever approach is clearer for the job.

## Step 5: Compress only the final extract

If the portal has a strict size limit, compress the extracted file after it is complete. Compressing earlier can make review harder and create extra work.

## Common mistakes

### Including pages the portal did not ask for

More is not always better. Extra pages can slow down review or confuse the upload category.

### Forgetting page order

If the extract includes multiple sections, make sure the final order still makes sense.

### Using weak file names

Clean, descriptive names make your records easier to manage later too.
